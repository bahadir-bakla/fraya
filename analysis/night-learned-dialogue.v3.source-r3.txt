TrustedCallV3 binds real turn/state/policy/API/model hashes, call ID, source event
ordinal and exact text. Reference admission additionally requires independent
question identity and immutable target mapping. These objects do not authenticate
their own construction; copied text, source enums and hashes are not a deployment
gate. No demonstrated lossless/current Freya code ingress is supplied here.

Historical reference registry fields explicitly retain kind, immutable reference
ID, completed spoken event ID/order, creation revision, question/call/policy/API,
target IDs, disposition epochs and component dependency tokens. Earlier completed
speech at state3/current4 may resolve; matching global revision is not required.
Snapshot reference anchors must agree with the independent registry. Opaque
component tokens are compared as nonempty strings, without integer conversion.
Offer acceptance binds the exact current spoken offer; readback affirmation binds
active readback. Candidate eligibility is descriptive and grants no permission.
New candidate terms block prior-reference confirmation. This conservative veto
is currently broad and remains an unresolved scoped-decoder limitation.

Candidate detector proposes typed Unicode source spans, clause-local c0 IDs,
competing-kind/exclusion diagnostics and explicit unsupported/no-candidate status.
No regex match is not evidence of semantic absence. More than16 candidates,
12clauses or16qualifiers causes bounded abstention with full coverage diagnostics.
Security answers require an independent field span; whole-turn surface heads are
masked for security questions or supplied mixed-turn security descriptors.
This is not a demonstrated automatic redactor for unmarked mixed secret content.
