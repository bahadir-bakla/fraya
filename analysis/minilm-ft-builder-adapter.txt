Child-only model API:
  FinetunedModel(request) validates the manifest, safetensors/config files and
  exact two-module runtime snapshot, then invokes the parent's pinned
  minilm_ft_eval.load_model(model_directory, device='cpu'). Torch uses 2 threads.
  FinetunedModel.predict(inputs) accepts only exact snapshots:
    {'current_utterance': STRING,
     'previous_utterances': [{'speaker': 'ASSISTANT', 'text': STRING}] or []}
  It returns one dictionary per input with the exact 7 domain + 4 source-act
  labels. Every head contains raw logit, finite sigmoid probability and the
  Boolean probability >= CAL-manifest threshold. 1.01 disables selection.
  Use build(request), rather than direct predict, to obtain source-bound rows.

Input/output binding:
  Only role/message from the supplied observed failed-call transcript file
  enters inference. Case identities, scorer fields, expected actions, domain
  labels, state, tool events and financial permissions are never features.
  Context is strict immediately preceding message adjacency. Any intervening
  system/tool/malformed message, USER turn or call boundary resets context.
  This is deliberately stricter than skipping transport events to find an old
  assistant question. It can omit useful context and must be reported as such.
  Blank, malformed or oversized USER messages produce explicit skip diagnostics
  and reset context before later USER turns. No hidden text truncation occurs.
  Limits: 512 observed rows/calls, 20,000 message entries, 16,384 codepoints per
  speech item, 2,000,000 accumulated observed context/user codepoints. Overall
  row/message/aggregate overflow rejects the entire result rather than clipping.
  Oversized/invalid assistant context is omitted; current USER can still remain.
  Output contains call_index, message_index, input_sha256, 11 head scores, and
  false bank_authority/UNKNOWN financial_authorization; it does not copy speech.
  input_sha256 binds canonical sorted compact JSON UTF-8 of the exact snapshot.
  source_sha256 binds the complete transcript file; request_sha256 binds the
  exact request including paths, source/model/runtime pins and child budget.

Validation and import scope:
  Exact keys, types, taxonomy, indices, input SHA, result/request/model/source
  pins, skipped records, finite logits/probabilities, exact sigmoid values and
  CAL threshold selections are checked. Duplicate JSON keys and nonfinite JSON
  constants are rejected. Model manifest paths cannot traverse, use links or
  enumerate executable Python files; all loaded artifacts must be listed.
  Required safetensors are encoder/model.safetensors and head.safetensors.
  Unlisted model files and extra runtime modules are rejected. Runtime source
  modules are explicitly loaded by their pinned file paths; caller-controlled
  sys.path is not inserted. A foreign preloaded minilm_ft_core is rejected.
  Parent runtime uses local_files_only/trust_remote_code=False and safetensors.
  The old BANKING77 head is never read or attached to the new encoder basis.
  Sources and model files are rechecked after inference. Hash checks detect
  substituted files; they do not replace the parent's trusted freeze or make
  arbitrary caller-supplied hashes into authentication.
