polarity, corrections and offer/readback references. The deterministic kernel

INTERFACE FOR SOL NOW
predict(input_snapshot, model_bundle) -> semantic_proposal.v1, pure and deterministic.
Input binds turn_id, state_revision, policy_hash and api_hash to exact current
customer text and its provenance, phase/current question, bank-returned target
candidates, pending component revisions, spoken offers and active readback.
The JSON design contains the complete field contract and strict schema.

Output carries primary and secondary acts, target-scoped clauses, per-component
absent/complete/unfinished/ambiguous status, asserted/negated/conditional/questioned
polarity, source spans, corrections, offer references and descriptive consent.
It emits no tool call, queue/outcome, permission, verified/recorded flag or final
normalized policy amount/date. Unknown/untrained/uncalibrated heads abstain.
The trusted wrapper stamps model and state bindings; model text cannot forge them.

Provide separate entry points for train, calibrate, evaluate and export_stdlib.

STATE AND GRAPH DESIGN
Represent immutable evidence spans, target records, component revisions, correction
episodes, source rules, spoken offers/readbacks, confirmation evidence, operations
and receipts. Edges express support, scope, negation, supersession, offer reference
and dependencies. Learned edges are candidates; authority edges come from actual
kernel/bank events. Persist a compact working projection, not the full transcript.

Per target/component keep value, status, revision, evidence and correction epoch.
If U is the unresolved set, C_new is a newly scoped correction and E_new is this
turn's explicitly completed, validated evidence for that episode:
    U_next = (U union C_new) minus E_new.
Old cached terms never count as new completion. Repeated fragments in one episode
do not reset independently completed siblings. Later genuine corrections create
new revisions. Unknown scope remains explicit uncertainty, not inferred from which
scalar happens to be absent. Resolve structure/target, then completion, then parse
only complete components. A complete amount must survive an unfinished date.

Every actual spoken offer gets an immutable ID, target set and exact terms/revisions.
Acceptance refers to that still-active offer, not a recomputed deadline/default.
Administrative detours retain those references and accepted facts. Corrections
invalidate confirmation and supersede only the relevant components. Readback is a
separate immutable snapshot, followed by a later clear affirmation of exactly it.
No learned affirmation alone grants consent. A missing/stale/ambiguous event cannot
reuse old consent. A false semantic prediction can still cause harm despite a
permission boundary: empirical semantic and bank-score gates remain necessary.

Collective scope must survive row splitting. Keep shared-date group and amount
scope (aggregate_total versus each/per_target). Resolve every explicit target
before mutation. Source rules determine per-product adjustments and precedence.
Deferred refusal/negotiation state must carry the target revision that created it;
a new valid proposal supersedes that old refusal and cannot later be overwritten
by its stale persuasion offer. Recorded promises remain immutable.

Measure accepted-frame risk and coverage together, plus per-head precision/recall,
scoped blocker recall, OOD false acceptance, NLL/Brier and exact offer/target accuracy.
Abstention is not success. Min(head confidence) is not joint correctness probability.
For zero unsafe accepted groups out of n independent groups, one-sided 95% binomial
upper error bound is 1 - 0.05^(1/n). A <=1% target needs at least 299 such groups even
with zero observed errors, before threshold-search corrections. Current data is far
too small. Bounds require independence/exchangeability, not arbitrary OOD assurance.

FINITE-SAMPLE CLAIMS AT THE RIGHT UNIT
Each independent sampled lineage/scenario group contains all its planned turns,
repetitions and contrast descendants. Let A=any accepted relevant proposal and
E=any wrong accepted proposal. Observed group selective risk is sum(E)/sum(A).
For m accepted IID groups and k errors, the one-sided exact upper bound U solves
sum_{j=0}^k binom(m,j) U^j (1-U)^(m-j)=alpha. For zero errors,
U=1-alpha^(1/m); m=0 is unqualified, U=1. At alpha=.05, zero errors among4 groups
still gives52.71% upper risk;7 gives34.82%;299 are needed for<=1%,598 for<=.5%.
These are conditional mathematical examples, not current independence claims.

Distinct lineage IDs, separate authors and more rows do not establish IID sampling.
Curated cases give finite-suite evidence unless a defensible sampling model exists.
Do not estimate effective sample size and insert it into exact binomial formulas.
Keep group exposure fixed; any-error probability changes with number of turns.
Group coverage can hide one easy accepted turn: also show row/complete-frame coverage
and safe recall (correct accepted / all eligible), counting abstention misses.

Fit calibration parameters on calibration_fit, choose thresholds on calibration_risk.
A finite K-rule sweep certified on the same risk set needs simultaneous alpha/K
(or a predeclared allocation). With K=11, zero errors needs537 accepted IID groups
for a1% upper target at overall alpha=.05. Alternatively select exploratorily,
freeze ONE candidate, test once on new independent blind qualification. Joint risk
and coverage statements at alpha=.025 each need368 zero-error accepted groups for
the1% risk target. Head/slice/repeated-look claims also consume the alpha budget.
No repeatedly inspected fixed-sample interval with favorable stopping. New adaptive
revision means new blind qualification; current v1 holdout remains diagnostic.

For bank score use actual all-three outcomes per scenario, not single-call rate
cubed. Report paired baseline/treatment outcomes with independent-scenario uncertainty
only when sampling supports it. Original tiny official suite is its exact finite
score; no population generalization inference follows. Require no observed new
critical violation, no protected-case regression and a useful margin frozen before
new qualification. Separate consumer-only repairs from learned-model contribution.

MODEL/CONSUMER CONTRACT
Build one evidence bag per target/component/current terms epoch before a transition.
For nonconflicting facts, merge must be invariant to extractor row permutation and
partition/coalescing. Deduplicate identical source events. Empty/absent means no new
fact. Conflicting asserted values without supported supersession need clarification.
Explicit correction order follows actual speech spans and reference edges, not JSON
array order. Once reconciled, apply one target patch, preserve independent siblings,
and only then choose clarification/readback. Learned output remains proposals;
revision changes, refusal invalidation and bank permission belong to the kernel.

Deferred refusal binds target disposition epoch, terms revision and spoken offer.
Fresh voluntary terms supersede obsolete refusal. An unfinished replacement starts
its own clarification episode; completing another target cannot revive the prior
refusal or spend an extra persuasion attempt. A blocked confirmation cannot become
collective refusal. Historical recorded receipts remain immutable; changing a paid
claim requires actual fresh scoped evidence and policy, never a global keyword.

Completeness/negation attach to their own spans. Earlier or quoted ellipsis cannot
erase a complete later clause. Preserve changed-term/withdrawal/stale-consent guards;
do not simply remove the raw veto or accept every extracted confirm.
