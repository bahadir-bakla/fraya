Hardening now in code
Atomic bounded JSON pointers reject invalid/nonfinite JSON, noncanonical Unicode
array indices and unsupported coverage updates. API payloads named tools, code,
pre_actions or _tool_ref remain ordinary data. Only graph action positions expand
macros; only actual hook/code_exec slots expand snippets. Private tool response
aliases bind actual operation names in routing; remaining unbound automatic
result namespaces are rejected by lint. Schema changes drive exact URL, method,
types, required fields and enums. Source hashes are checked again before prompting.
Budget checks occur before and after trace persistence, before mutation dispatch.
