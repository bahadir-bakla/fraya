STATE LANES
financial: F,N and negotiation-progress flags commit as one patch only after all affected target/aggregate/component constraints are preflighted. No shared-state mutation inside per-row iteration. Existing valid pending facts remain on abort.
safety: Barrier creation/strengthening and consent invalidation are monotone within a turn and survive rejected financial preflight. Do not restore old consent by restoring the whole snapshot. A malformed whole payload creates a global uncertainty barrier without salvaging individual untrusted rows.
questions_and_quarantine: Independently understood questions remain obligations. Valid sibling proposal evidence is retained in Q with batch/source/version and uncommitted status, not installed as agreed/current F. Rejected data never creates tool parameters or refusal counters.
repair: A later repair must reference the rejected batch/affected assertions; re-resolve and revalidate the entire proposed financial patch against a new snapshot. Discard obsolete rows explicitly; never auto-promote a once-valid prefix from Q.
receipt: Receipt transitions update J/confirmed bank facts through their own revision-checked transaction. A concurrent receipt invalidates stale user-turn preflight; never overwrite confirmed bank state with an old staged copy.
error_barriers: Every rejected financial batch invalidates consent for its affected targets and blocks its queued plan; unknown/ambiguous scope blocks globally. Changed/pending/conflicting component cells revoke dependent certificates even when no permission row exists. Preserve old facts as last-known evidence, not authority to ignore the new ambiguity.

RELATION AND PERMISSION RULES
cell_selection: Candidates(target,component)=maximal scoped assertions in the relation DAG. Equal normalized complete maxima collapse to one value; unequal maxima are conflict. An unresolved replacement is never overridden merely by finding an older complete value.
interturn: New positively asserted terms on a later turn may supersede prior unrecorded component facts under source semantics; add explicit temporal edges in IR. Multiple incompatible assertions within one turn need an explicit relation or remain conflict. Recorded promises are immutable.
fill_vs_correction: need(role=fill) can be discharged by an independent complete value for that cell. need(role=replacement, correction_of=e) remains unresolved unless a later linked completion fills it. role=unknown is conservative unresolved, not silently fill.
aggregate: An aggregate T over targets U remains a joint constraint. Permit an allocation only if each A_p is explicit or uniquely source-derived (current export supports total=sum past_due => full balances), sum A_p=T, and every A_p respects per-product policy. No proportional/equal split invented. Missing allocation => clarification; impossible sum => policy rejection; both yield empty financial patch.
rollback: FinancialAbort => F_after=F_before AND N_after=N_before AND progress_after=progress_before. B may grow; C may shrink; Q/questions may grow. Therefore whole-State equality is the WRONG rollback assertion.
idempotence: Replaying same stable turn/event or receipt ID changes neither F/N/J nor revisions a second time. Two distinct real turns with identical words are not automatically duplicates.
independence: Act permutations preserving event IDs, relation graph and target semantics must preserve normalized preflight/commit result. Arrival order of receipts, source speech turns and correction EDGE DIRECTION are meaningful and not freely permutable.
within_turn: Map barriers to severity clear<needs_fresh_readback<unresolved; take pointwise maximum over expanded target scopes. Unknown scope becomes global. Therefore complete withdrawal cannot downgrade an unfinished-permission barrier in the same packet.
across_turns: Only the explicit later resolution/readback/confirmation transitions may lower severity. Union provenance/reasons within a turn; never choose the last permission row.
joint_certificate: If any target in a joint certificate intersects a new barrier/error/changed component, revoke the whole certificate; retain independent target facts and refusal events.
chronology: earlier(turn_a,turn_b) is an established event-stream ordering relation, not lexicographic or numeric comparison of opaque IDs. If order cannot be established, no confirmation certificate.

DISPATCH BOUNDARY
point: In one serialized state transition, recheck plan readset/version and all guards, freeze body, and mark operation dispatched before invoking the bank tool. No tool invocation occurs during preflight.
withdrawal_before: A withdrawal/barrier committed before this transition blocks dispatch; a previously prepared plan is not a continuing authorization.
withdrawal_after: After dispatch starts, preserve in-flight/unknown journal status. A later withdrawal stops further unsent effects but cannot establish cancellation of the sent operation. A bound success still creates a truthful recorded fact; source disallows changing/cancelling it in-call.
unknown: A local crash after marking dispatched is not proof the bank did nothing. Missing result is unknown and cannot be retried as failure without a source no-effect guarantee.

def cell_reduce(atoms, edges):
    # Normalized atoms for ONE target/component; no policy/API/ingress authority.
    ids = [a['id'] for a in atoms]
    if len(set(ids)) != len(ids): return {'status': 'reject_duplicate_id'}
    by_id = {a['id']: a for a in atoms}
    children = {i: set() for i in ids}
    indegree = {i: 0 for i in ids}
    for old, new in edges:
        if old not in by_id or new not in by_id:
            return {'status': 'reject_missing_node'}
        if new not in children[old]:
            children[old].add(new); indegree[new] += 1
    todo = sorted(i for i in ids if indegree[i] == 0)
    visited = 0
    while todo:
        i = todo.pop(); visited += 1
        for j in children[i]:
            indegree[j] -= 1
            if indegree[j] == 0: todo.append(j)
    if visited != len(ids): return {'status': 'reject_cycle'}
    maximal = [by_id[i] for i in ids if not children[i]]
    if any(a['kind'] in ('replacement', 'unknown_need') for a in maximal):
        return {'status': 'pending'}
    values = {a['value'] for a in maximal if a['kind'] == 'value'}
    if len(values) > 1: return {'status': 'conflict'}
    if values: return {'status': 'value', 'value': next(iter(values))}
    return {'status': 'pending' if maximal else 'missing'}
