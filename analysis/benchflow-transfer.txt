ASSUMPTIONS THAT MUST CHANGE
1. Old assumption: A task prompt and representative input sample fully describe policy.
Replacement: Consume all supplied briefs and raw documents plus that brief's OpenAPI; resolve explicit overrides, exceptions and code-list mappings with source-span evidence. Samples may not cover authoritative branches.
Evidence: E01, E02, T02, T10

2. Old assumption: Known bank numbers, field names, enums, identity questions or calendar can be compiled into generic prompts.
Replacement: Keep generic algorithms; compile every instance value and tool schema from current input. Record provenance and reject unresolved required mappings. No final-brief facts enter builder code.
Evidence: E01, E04, T02, T06

3. Old assumption: Output correctness is a static file/schema check.
Replacement: Check observable action order, state, bank effects AND truthful/policy-compliant speech. Runtime confirmation refers to a versioned current proposal and is invalidated by corrections.
Evidence: E03, E37, T01, T07, T08, T09

4. Old assumption: One scalar amount/date/status/attempt counter represents the customer.
Replacement: Maintain ordered product records with independent proposal, confirmation version, persistence result, attempts, deadline and note state; aggregate closure using current brief precedence.
Evidence: E02, T08, T10

5. Old assumption: A call to a tool means its effect occurred.
Replacement: Only declared successful response authorizes recorded events or success speech; keep attempts and committed effects separate, retain partial per-product success and derive terminal outcome from actual effects.
Evidence: E03, T01, T08, T10

6. Old assumption: Calendar uses host clock and a fixed parsing convention.
Replacement: Evaluate current-input date/time policy against supplied now and input calendar; preserve spoken corrections and confirmation boundaries. Current A's conventions are instance facts.
Evidence: T02, T06, T07, T08

7. Old assumption: Creator must never run a full simulation; long repair can defer final write.
Replacement: Builder may run its agent's actual tests within 30 minutes. Reserve completion/export/trace time, await terminal results and preserve best fully validated candidate; a placeholder agent has no guaranteed minimum score.
Evidence: E04, E05, T01, T03, T05

8. Old assumption: One green run or three copied directories establishes robustness.
Replacement: Separate deterministic build replay from stochastic call evaluation; assess complete-case pass across required repeated runs and calendar/style changes. Public runs guide repairs, not claims of hidden robustness.
Evidence: E14, E23, T01, T02

9. Old assumption: Copy the old test-directory ban, upload ban and infrastructure keyword stop rules.
Replacement: Allow authorized visible kit tests and workflow submission; protect credentials, hidden answers and scorer integrity. Classify infra from structured statuses, not words inside customer data. Keep live simulation serial per workspace.
Evidence: E06, E24, E25, T02, T03, T04

10. Old assumption: A frozen oracle from the generated draft is independent.
Replacement: Construct/check the oracle from resolved original brief plus OpenAPI, then freeze it before candidate repair. A generator omission must not become the expected outcome.
Evidence: E02, E03, E38, T01
